# Iris Streamlit ML Application

## 🌸 About the Project

This project is a Machine Learning web application built using
Python and Streamlit.

The application predicts the species of an Iris flower based on:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 🌺 Iris Species

The model predicts three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
